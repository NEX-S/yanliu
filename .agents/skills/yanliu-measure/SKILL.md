# 砚流测量

只测本次需求或已证实问题。先确定用户路径、待检验假设、指标和接受/停止条件；没有用户给定数值时按本次用途说明判断依据，不发明通用硬门。当前产品范围见 [README](../../../README.md)。性能比较不自动要求新质量数据；新泛化结论才需要未观测留出。结构重构中的行为回归也不自动变成性能或质量比较，不为此新建评测或硬件框架。

## 基线与实验

- 记录旧/新源码快照、模型/词库/数据哈希、命令、feature、RUSTFLAGS 和环境；worktree 不会携带未提交修改。只改变被检验因素，确认比较的是对应 binary。原始结果放 results/ 或现有缓存，无需另造状态文件或产品接口。
- 计时与本任务的编译和其他测量串行，不停止无关用户进程；有资源竞争就保留限制。相同硬件、affinity、输入、预热下交错比较多轮，报告分位数、最坏值和实际评分次数，不挑最好一轮。解码、模型评分、IBus 信号与 Shell 绘制分别计量，跳过模型不等于推理变快。
- 增量/缓存测量走真实 Session 逐键路径，按改动覆盖首键、歧义、长串、分隔符、编辑/光标和失效回退。声称候选行为不变时逐帧核对 text/consumed/source/静态 score 位及排序决定；只有涉及评分实现或声称数值等价时才核对模型分数。top1 相同不代表完整等价；数值近似预先声明允许误差与决策变化。

## 质量与结论

- 候选质量用 `yanliu evaluate` 检查 [data/eval](../../../data/eval/README.md) 的数据或 `scripts/ime_lab.py` 生成的合成案例，与 IBus 共用 Session 路径。调参只用开发数据：context-dev-v2、replay-v3 dev 或本次生成的案例；replay-v3 test 已观测，只作回归。新泛化结论需要先锁定未观测来源、相关分组、排除和许可，再冻结策略评估，不重新切分暴露数据冒充独立留出。
- 推理只读 input/context，不读 gold；测试 gold 仅用于固定的污染排除和最终评分。按作者、近重复等相关组拆分/统计，披露训练重叠、自动拼音、多音字和抽样限制。
- 转换命中只计完整消费且非 Completion。保留逐例配对、完整分母、top1/top5/recall、救回与破坏、上下文/来源分桶及实际候选上限。外部 profile、wrapper CPU 和状态机测试各自只证明所测范围。
- 按比较前确定的需求判断收益和退化；性能报告收益与实际失效路径，更换默认模型还检查逐键延迟、内存、质量和安装产物。评估请求交付判断与证据，只有本次需求包含实施时才整合收益值得其复杂度的修改，最终证据绑定交付源码。
- 有结论就停止，不通过换指标、重切数据或不断扩大样本延长实验。撤销本次不再使用的实验代码、清理本次的临时状态，保留报告依据的原始结果；不删除已有模型或数据。保留未覆盖范围，不宣称 SOTA、自然人群准确率或绝对最优。
