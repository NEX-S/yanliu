# yanliu-25m-v2

砚流可选的 25M 中文候选排序模型。在本轮开发集和已观测 replay 上质量较高，CPU 成本也明显较高。模型只根据有限前文为已召回的真实候选排序，不扩大召回、改变候选身份或消费量，也不注入答案。

## 模型与训练

实际 **23,536,128 个参数**，8 层、8 个注意力头、宽度 448、context 64、dropout 0.1，词表 9,358 项，输入和输出嵌入共享。权重文件为 `sentence-model.safetensors`（24,028,120 bytes）；二维权重矩阵采用逐行对称 INT8 量化，位置表及其余参数保留 FP32。SHA256：`724d1dad100a98c799d526b0c699d5f3eccf0f995d53bd5634ad98a0cdcdf7b1`。

从全随机权重初始化，没有加载旧模型。52,270,719 字符训练文本完成 **400M 有效 targets、98,039 次更新**；PAD/UNK 目标不计入有效 targets。按文本 dev 交叉熵选中未跑满的第 8 轮检查点（CE 3.1717576242）。随后用 80,000 条真实候选样本微调 1 轮，53,329 条参与排序损失，共 3,334 次更新，并混合 2,008,517 个普通文本有效 targets；排序 CE 与文本 CE 系数均为 1。INT8 实际 CLI dev 按组等权 top1 选中第 1 轮，平局取较早轮次。优化参数、源码、数据和阶段权重哈希见 [provenance.json](provenance.json)。

## 质量与范围

选模开发集全量 1,917 条、1,386 组：top1 **1,344/1,917（70.11%）**，top5 1,488/1,917，召回 1,583/1,917，组等权 top1 **67.09%**。现有 7M 的 top1 为 1,270/1,917、组等权 63.65%。开发分数已经用于选模，不能估计独立泛化。

冻结选择后，三个固定模型各执行一次新来源 holdout，全量 **1,750 条、543 组**，未因结果删减分母。本模型 top1 **1,326/1,750（75.77%）**，top5 **1,462/1,750（83.54%）**，召回 **1,533/1,750（87.60%）**，组等权 top1 **77.04%**；现有 7M top1 为 1,252/1,750、组等权 71.14%。此后没有据 holdout 调整模型、阈值、策略或默认选择。NaturalConv 为 1,000 条、534 个新闻组；CPED 为 750 条、仅 9 个独立剧集组，样本数不等于独立组数。这是单次冻结留出结果，源文本及自动注音仍可能有误，不能称为自然用户输入准确率。

已观测回归集 top1：common 23/26；context 21/24（现有 7M 为 22/24）；replay **1,415/2,000**（现有 7M 为 1,380/2,000）。这些旧资料不是新独立留出证据。完整分母、分组口径、来源指标和各模型对照保留在 provenance 的 `metrics`。

## CPU 成本与系统检查

本机固定 CPU 2 的真实 Session 回放共 3 轮，每臂 1,062 帧，其中 654 帧评分；每轮三臂都评分 218 帧、1,935 个已知候选，候选池和轨迹一致。评分帧的 action + promotion wall p95：现有 7M **6.472308 ms**、4M **4.153561 ms**、25M **35.701632 ms**。回放后进程 RSS 中位分别为 **113.84375、110.38671875、133.89453125 MiB**。每轮预热和启动时间不计入上述评分时段；OS 文件缓存未受控。这些数值属于固定 CPU 回放，不是物理按键、GNOME 绘制或键到屏幕延迟，也不证明全局最优。

私有 IBus 原 5 组检查中前 4 组通过，第 5 组在每语境 4 次明确纠正后未达到指定首选，选择计数和参数更新确已持久化。额外独立的每语境 8 次明确选择场景通过了两个指定首选、重启持久化和敏感输入不学习检查；原失败保留，这不能证明最少需要 8 次。这些只属于私有总线协议集成检查，不证明真实桌面交互或延迟。

## 数据与许可

训练来源为固定版本的 LCCC-base、中文 Wikipedia 20231101、COIG-CQIA 人类回答、TNEWS、NaturalConv 和 CPED。数据先按会话、页面、问题、新闻或剧集分组拆分，再清洗和精确/近似去重；排除既有评测，新来源 dev/holdout 另对照旧训练文本排除重合段落。不依据召回或模型分数筛选自动注音样本。没有使用私人对话、应用上下文或系统学习。

NaturalConv 固定 12 段训练抽样发现 13 处明确及 2 处疑似问题，不能据此估算全库错误率，训练仅取约 2M 字符作口语补充。pypinyin 0.55.0 自动注音不是人工金标，尤其多音字可能有误；CPED dev 的 440 条也仅来自 5 个剧集组。固定下载 URL、来源版本、原文件哈希和覆盖统计见 provenance。
