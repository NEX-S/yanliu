## 2026-10-25 续训停止检查

以当前本机 `ca1f0279…` 4M 权重为父模型，使用当前源码提交 `3bdf501` 对应的冻结 CPU CLI 和词库，复用 7,384 条公开训练案例、923 条已观测开发案例与普通文本保持项。XPU/FP32、batch 8、text-batch 16、学习率 `3e-6`、seed `20261025`，固定再训练两轮，共 1,720 次更新；没有扩大模型或扫描其他参数。仍按真实 INT8 CLI 的分组等权首选指标选择，包含未更新的 epoch 0，平局选择更早轮次。

原模型、第 1 轮、第 2 轮的首选命中分别为 **702/923、702/923、701/923**，分组首选分别为 **81.0856%、81.0856%、80.9912%**，前五命中分别为 835、838、837。第 1 轮的前五改善没有提高选模主指标，第 2 轮出现退步，因此选择 epoch 0，停止这条继续训练路线。保留原始 `ca1f0279…` 权重字节，不以 epoch 0 重新导出文件替换它；重新导出已通过候选与评分行为一致性检查，但 metadata 不同，文件哈希也不同。

当前 CLI 下的原模型回归：修复案例 20/20、常用词 25/26、语境 21/24、reviewed8 为 4/8、replay dev 为 749/1,000、已确认问题 321/321、保持案例 2,956/2,956、replay test 为 1,419/2,000。修复集相较历史 19 条版本增加了“堤岸”案例，本轮完整计入 20 条；其他数据文件与旧记录哈希一致。各集合存在训练、开发或历史观测关系，不能合并分母或用作新的独立泛化成绩，也不能把当前 CLI 的分数与历史 CLI 分数直接归因于这次训练。

配方、逐轮完整开发报告、当前回归及本地模型包保存在 `results/model-sweetspot-20261025/`。本轮没有读取系统学习，也没有改变桌面安装、公共默认下载模型或声明权重已具备公开再分发许可。公开再分发仍取决于下述来源条件的核实。

## NaturalConv 来源更正

历史模型的 `LICENSE`、`NOTICE` 与冻结配方写有“数据卡未声明许可”。同一训练来源版本实际包含独立的许可证文件：

- 来源版本：`xywang1/NaturalConv@adb38574e8014ada1d8404247167582e76b22d05`。
- [固定版本 LICENSE](https://huggingface.co/datasets/xywang1/NaturalConv/blob/adb38574e8014ada1d8404247167582e76b22d05/LICENSE)：3,634 bytes，SHA-256 为 `b51724699c7602950328471609ef586995eb7ecb870a93bc45eea79cd1a9946e`。
- [作者仓库](https://github.com/naturalconv/NaturalConvDataSet)也明确说明非商业用途限制。

条款第 3 节只向个人、非商业科研、开发、测试及指定学术发表和技术活动展示等用途授予有限许可。第 4 节限制数据及其衍生作品的分发、转售和其他使用，并限制通过腾讯以外的来源提供数据。

这补齐了对实际条款的记录；训练权重是否属于条款中的衍生作品仍需单独确认。现有材料不足以宣称整份混合来源模型可无条件商用或自由再分发。本机修复版继承了父模型的训练来源，继续微调没有消除这些来源条件。

## 尚未齐备的发布材料

2026-10-25 再核对第一方材料：NaturalConv 固定 LICENSE 第 4(c) 节限制数据及衍生作品的分发，但没有明确训练权重的归类；现有材料不能据此确认这些权重的公开分发权限。[COIG-CQIA 固定数据卡](https://huggingface.co/datasets/m-a-p/COIG-CQIA/blob/8b55868c6168adf86c30e7ca0f782cca1c514297/README.md)仍缺明确许可，[TNEWS 固定数据卡](https://huggingface.co/datasets/clue/clue/blob/28178267a609dd08bdc703dd6c931dfc2c2f4431/README.md)声明 `unknown`。这属于授权范围尚未确认，不能表述为已获自由再分发许可，也不足以断言所有训练权重都被明确禁止发布。继续微调不消除父模型的来源条件。Wikipedia 的文章归属和各来源原始声明需要随适用条件保留。CPED 的仓库许可与其电视对白来源分别记录。新增 DeepSeek Flash 合成样本也需要保留生成记录与适用的服务输出条件。
