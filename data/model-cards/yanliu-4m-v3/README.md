# 砚流 4M v3：续训停止后的选定模型

448万参数，6层、192隐藏维度、4个注意力头，9,358字符词表、64位置窗口；二维权重逐行INT8量化，供CPU离线推理。

这是已有本机4M修复模型的继续训练版本。从7904a8a4权重出发，在Arc B390 GPU以FP32训练3轮、2,577次更新，按固定923条开发数据的分组首选指标选择第3轮。训练使用真实CLI菜单的排序交叉熵、源模型正确首选的保持损失、缺失目标的后缀监督，以及原4M在普通文本上的KL保持；没有增加25M候选蒸馏。

本轮7,384条输入包含4,096条新生成的公开监督案例和去重后的既有案例。原文复用已核验的公开语料；注音由固定版本拼音库和有署名的十短语补充生成，不是全量人工金标。训练集、已观测开发集与固定回归结果不能作为独立泛化证明。

固定CLI回归中，相比7904a8a4，DEV首选740→744/1000，已观测TEST首选1410→1415/2000，24条语境18→21；两套旧正确案例321与2956均保住。也有具体退步：DEV有15条救回、11条损失，TEST有25条救回、20条损失。各集合重叠，不能合并成总体准确率。这些结果只覆盖所记录的运行快照；当前代码的验证和安装决定另见本机实验结果。

## 2026-10-25 续训停止检查

以原模型继续训练两轮，学习率 3e-6，XPU/FP32，复用已观测的 923 条开发样本。原模型及第 1 轮均为 702/923 首选，第 2 轮为 701/923；分组首选分别为 81.0856%、81.0856%、80.9912%。按分组指标、平局取更早轮次选择 epoch 0，故保留原始 `ca1f0279a72213510471b0f9bda7876b8dc6b40cdb2a4c4d7c227e737feebe05` 权重字节。第 1 轮前五命中有小幅改善，但未提高选模主指标，不继续追加轮数。

这些是已观测开发/回归材料，不能证明独立泛化。系统安装未改变。该包继承父模型的完整来源条件；NaturalConv 对训练权重的再分发适用范围及 COIG-CQIA/TNEWS 的授权尚未确认，本发布没有声明这些来源赋予统一、无条件的模型许可。
