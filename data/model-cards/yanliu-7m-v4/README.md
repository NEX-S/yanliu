# 砚流 7M v4

`models-v4` 的可选预发布模型，供本机 CPU 离线推理。实际 7,188,992 参数，6 层、256 隐藏维度、4 个注意力头，9,506 字符词表、64 位置窗口；INT8 文件 7,488,880 bytes。公共默认仍是 models-v2 的 4M。

权重为 `sentence-model.safetensors`，SHA-256：`64c8b72fac097c22c3858d2e499b1b9020c324d20d774ce756af134085736354`。原字节及嵌入元数据完整保留。

从各自真实 FP32 父模型继续预训练 100,000,000 个有效目标，未从 INT8 反量化恢复。随后完成三轮真实 CLI 候选排序训练，INT8 开发集分组首选均未超过 epoch 0，因此交付续预训练后、未增加排序更新的 epoch 0。训练为 Intel Arc B390 / BF16，主参数 FP32。父模型链与配方哈希见 [provenance.json](provenance.json)。

训练正文共 76,786,854 字符，含固定公共中文来源与明确授权的本地助手中文：Claude 1,246,882、Codex 4,999,019、Grok 464,812 字符。用户于 2026-11-07 明确授权公开发布选定训练权重；原始对话、训练正文及私有逐条记录不发布。private-derived 来源分类和历史元数据（含本机路径）保留，没有匿名化或不会记忆、复现训练内容的保证。系统选词记录未用于训练。

## 已观测候选结果

同一 CLI / Session 路径对照历史父模型 INT8 与本版。以下依次为首选、前五、召回命中数，分母包含未召回目标：

- 开发部分 1,609 条：历史 1362 / 1517 / 1564 → v4 1414 / 1537 / 1566。

- 已观测句子 2,000 条：历史 1443 / 1768 / 1857 → v4 1462 / 1775 / 1857。

- 本轮留出 583 条：历史 434 / 516 / 556 → v4 453 / 524 / 558。

3,609 条开发数据参与选模，其中 2,000 条句子早已观测并纳入回归保护；583 条只与本轮训练隔离，无法证明未进入历史父模型预训练。自动注音和标签可能有误，各面板不可合并为独立测试成绩，也不等于日常输入准确率。

已观测小面板中，语境首选由历史 7M 的 22/24 降为 21/24；修复集由 10/20 升为 15/20；常用词均为 23/26。总体结果支持优先尝试 7M v4，但并非所有语境都有提升。

## CPU 范围

仅比较本批 4M / 7M v4。Intel Core Ultra X9 388H，固定 CPU 4，预热一次后按 4M、7M、7M、4M、4M、7M 串行交错回放，每版三次、每次 354 帧，共 1,062 帧。每帧 action + refine + apply 墙钟耗时，本版 p50 **4.147102 ms**、p95 **26.275119 ms**、p99 **69.802606 ms**；7M 总 CPU 时间为 4M 的 **1.52699 倍**。范围是含有界模型召回的进程内 Session，不含 IBus、GNOME 绘制、真实键盘或键到屏幕延迟，未控制系统文件缓存；不是历史模型 CPU 对照。

## 使用与来源条件

从 [models-v4 发布页](https://github.com/NEX-S/yanliu/releases/tag/models-v4)下载、校验 SHA256SUMS 并解包。首次安装时指定如下目录；已有安装切换模型时，在命令末尾加 `--upgrade`：

```sh
YANLIU_MODEL_DIR=/absolute/path/to/yanliu-7m-v4 \
  ./packaging/install-local.sh
```
