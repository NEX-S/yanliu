# 评测数据

以下候选评测 JSONL 可直接作为 `yanliu evaluate --data` 的输入；`input`、`context`、`gold`/`golds` 之外的字段只是来源记录，评测时忽略。gold 只用于评分。

- `context-dev-v2.jsonl`：24 条本项目自写的上下文消歧案例，例如前文“今年暑假我们准备去”后的 `xian` 应为“西安”。随仓库许可证（GPL-3.0-or-later）发布。
- `common-words-v1.jsonl`：26 条本项目手写的常用虚词、软件术语和 `kaiyuan` 同音词回归，包含“事件/时间”“集成/继承”以及“开源/开元”等相反语境。随 GPL-3.0-or-later 发布。案例已用于候选修复，模型仍可能误排；它们用于保留逐例收益与退化，不是独立留出或全对验收门。
- `candidate-repairs-v1.jsonl`：20 条来自 2026-10-22 公开 DeepSeek Flash 合成记录、经本项目复核读音和前文的开发回归，涵盖完整词被组合顶掉、软件术语消歧、多音字注音，以及 `dian → 堤岸` 的跨音节边界转换。每条保留原案例 ID 与响应 SHA-256；读音修正是数据注解，不是运行时词语加分。项目整理部分随 GPL-3.0-or-later 发布。这些案例已用于诊断或训练，不能当作新的独立评测。
- `pronunciation-dev-v1.jsonl`：17 条词组读音开发诊断。16 条为本项目自写并明确标注拼音的案例，涵盖“戒指/价值”“是吗/什么”、合法的“什锦/便宜”、“观音/乐于”等跨词边界及“都会”的副词与城市含义，随 GPL-3.0-or-later 发布。另 1 条复用 Tatoeba DEV 原句“我每次听这首歌都会听到哭”，仅将“都”的误注 `du` 改为 `dou`，保留原作者、来源、CC BY 2.0 FR 许可、原案例 ID 和旧输入；历史 replay 文件保持不变。此文件供比较真实拼音下的候选与检查读音规则的副作用，未加入训练，不是人工标注的独立留出，也不要求当前模型全部命中。
- `annotation-repairs-v1.jsonl`：3 条经过读音复核的 Tatoeba DEV 案例，分别为“我每次听这首歌都会听到哭”“我姐姐每天都会洗澡”和前文“我相信”后的“一切都会好起来的”。只将副词“都”的误注 `du` 改为 `dou`，原文、前文和可接受答案保持原样。每条保留原作者、句子链接、CC BY 2.0 FR 许可、分组、原拼音及原始 JSONL 行的哈希与位置；改读音的依据是句义，未参考候选命中。第一句也在 `pronunciation-dev-v1.jsonl` 中，跨文件汇总须去重，不能当作新增独立样本。历史 replay 文件与成绩保持不变。
- `replay-v3-dev.jsonl`、`replay-v3-test.jsonl`：由 Tatoeba 中文句子生成的 1000/2000 条整句案例，各一半以原句前缀为上下文。拼音由 pypinyin 对整句自动生成后再切分，可能有多音字错误，不是人工金标。按作者和近重复关系分组拆分，DEV/TEST 只有 186/352 个独立组，每组最多 20 条，条数不代表独立样本数或自然使用频率。构建时排除了此前使用过的评测文本和本地可读的 C4 匹配，完整 C4/LCCC 训练重叠未知。署名与许可（CC BY 2.0 FR）见 [replay-v3.NOTICE](replay-v3.NOTICE) 与[第三方说明](../THIRD_PARTY.md)，选择规则与哈希见 [replay-v3.lock.json](replay-v3.lock.json)。

这些数据都已被观测过：调参使用上述开发诊断与 `replay-v3-dev`，`replay-v3-test` 只作回归检查。它们不能证明自然输入准确率或独立泛化；新的泛化结论需要先锁定未观测的数据来源。

`learning-context.jsonl` 是 `yanliu learning replay --data` 的公开纠正序列，供检查“乘火车前往／此时此刻 + xian”的相反偏好与保存重载。它使用明确的 `select` 和原始消费字节，没有 gold 字段，不能交给 `evaluate`。案例随 GPL-3.0-or-later 发布；它们是开发回归，不保证任意语境都在相同次数内学会。命令见[学习回放](../../docs/DEVELOPMENT.md#回放个人学习)。

`learning-readings.jsonl` 使用同一回放入口和完整词库，包含 13 行本项目自写的公开纠正与查询。它复用上述词组读音诊断中的“什锦／交通方便宜居／观音乐于助人”，依次查询基线、明确选择三次，再查询用品语境的“湿巾”，检查非首选学习、上下文区分与保存重载。此文件同样使用 `select`，随 GPL-3.0-or-later 发布，不供 `evaluate` 使用，也不保证其他模型或语境在相同次数内学会。

`replay-v3.lock.json` 是历史构建记录，其中 `input_hashes` 保留了当时用于排重的旧评测文件与本地语料哈希；这些输入和旧 builder 不随当前源码提供。仓库提供可直接运行的成品、逐句署名、上游来源和成品哈希，不承诺仅靠当前仓库完整重生成该历史划分。
