# 训练输入

`homophone-pairs-v1.json` 是本项目手写的 120 对公开中文词，随仓库按 GPL-3.0-or-later 发布。每对两个目标的无声调全拼由 `pypinyin==0.55.0` 验证相同，不包含用户对话、应用上下文或个人学习。它为合成语境提供明确目标，避免教师重复提示示例或把不同拼音词误作同音词；词对本身不是自然输入频率或人工标注的候选准确率数据。

`scripts/ime_lab.py --pairs data/training/homophone-pairs-v1.json` 只向 deepseek-flash 发送这些明确的公开目标和抽象生成要求，让教师为每词写两条能区分另一词的前文。配合 `--generate-only` 可以生成后先冻结相关组，不观测模型评分。教师可能写出语义含混的前文，自动注音也可能与特定语境的读音不同；结构校验不能证明人工金标质量。原始请求、响应、拒绝原因和词对哈希保存在指定的新输出目录，不把生成失败计作训练覆盖。

划分训练、开发、留出时，同一全拼、相同目标和相同或近重复前文应放在同一相关组。先固定划分与排除规则，再训练或比较模型；已参与调参的案例只作开发或回归。原有 `data/eval` 数据均已观测，不能重新切分为新留出，也不将其 test 标签用于训练。模型未召回、语言评分中性或短名单外的目标可以不参与训练损失，仍须保留在评估分母并报告原因。

`scripts/train_ranker.py` 只读取显式的 train/dev 文件。默认以现有架构、单次语言评分、实际词频约束和提升门槛做小步监督训练；不自动扩大模型、修改词库或安装 checkpoint。每个输出目录绑定来源与实际程序，保存每轮 int8 开发结果、完整候选身份、收益与退化；模型原始许可证与署名随导出 metadata 保留。最终模型是否交付取决于未观测留出、固定回归和实际运行代价，不能只依据训练损失下降。
